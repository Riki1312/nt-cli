# Comment discussions and reactions

## Implemented

v0.3.0 adds selected-content comments, explicit discussion reads/replies, and own-account reaction controls. Comment reads now return structured JSON with stable provider references, available authors, anchors, counts, omitted discussions, and cursors. This changes the pre-1.0 output contract; `--raw` retains the MCP result.

Authenticated tool discovery exposed input schemas but no output schemas. Controlled writes on an authorized scratch page established actual response envelopes. Only synthetic fixtures are committed. Notion's rendered comment bodies contain unescaped XML-like content, so parsing reads metadata wrappers and preserves bodies opaquely. Availability-only responses do not prove an empty discussion history.

MCP operations and discovery have a one-minute deadline; refresh has a separate 30-second limit. Redirects are disabled and uncertain writes are not replayed by nt. Explicit provider status/code takes precedence over words in quoted content when classifying errors. This corrects a live selector failure that was previously labelled a missing resource.

## Verification

- Live page and selected-text comments; inline anchor readback.
- Replies retained the original discussion, including a bare-ID target with `--page`.
- Newlines and Unicode survived posting and reading.
- Repeated reaction add/remove was idempotent; normalized output preserved current state.
- A nonexistent selection failed and did not produce a page-level comment.
- Synthetic partial/cursor histories, unknown completeness, malformed metadata, opaque body injection text, request validation, stdin, provider failures, raw results, and mismatched write receipts.
- Formatting, vet, builds, and race tests on Go 1.24.0 and the pinned release toolchain; four-platform snapshot archives and Homebrew formula packaging.

## Limits

Live acceptance did not force provider history truncation; those contracts use documented shapes and synthetic fixtures. Tool availability and plan restrictions remain provider-controlled. Existing tests are local and credential-free; the scratch-page exercise is a manual acceptance check. Notification delivery, requester authorization, deduplication, and conversation routing belong to callers.
