# 2026-11-05

## v0.3.0 foundation

- Prepared [the comments design](../comments.md) before feature commands: selection targeting, explicit discussions, own-account reactions, structured output, and visible completeness/continuation.
- Inspected live hosted schemas with a temporary read-only probe. The probe was removed; no consumer CLI was replaced and no live comment, reply, or reaction was posted.
- `nt tools NAME` now exposes the actual description and JSON schemas. Discovery follows result pages and fails above 1,000 tools rather than returning a partial list.
- Token discovery/refresh share a 30-second bound without changing login identity or scopes. MCP operations and HTTP requests have one-minute bounds. The HTTP client refuses redirects. Local servers verify credential targeting, no redirected/replayed POST, a lost response, and cancellation. A first cancellation fixture stalled during server cleanup; explicit fixture release corrected the test, and the full rerun passed.
- Prepared `make fmt` / `make check`, race tests, pinned CI on Go 1.24.0 and 1.27.3, and a tag workflow gated on checks.
- Updated archive format syntax and aligned release/MCP version metadata. Preserved the existing macOS/Linux Homebrew formula with the pinned GoReleaser v2; cask migration changes installation/signing and is separate.
- Tests, vet, formatting, and builds passed on the normal and minimum Go toolchains. A checksum-verified GoReleaser 2.20.0 snapshot built four archives and generated the formula without publishing. `goreleaser check` still reports the documented formula-publisher deprecation; snapshot packaging succeeds.

## Request-side feature slice

- Added selected-content Markdown comments, discussion read/reply with inferred page IDs or explicit bare-ID context, continuation cursors, and own-account react/unreact.
- Kept original MCP payloads available through `--raw`. Comment writes require actual returned comment/discussion IDs before reporting a confirmed normalized result; unknown successful bodies fail visibly without a retry.
- Tests cover exact hosted request shapes, Unicode/multiline stdin, invalid input/flags before authentication, explicit provider denial, missing write IDs, and a single raw provider call.
- Split comment operations out of the general page handler. The only module change promotes the already-used flag parser to a direct dependency; no dependency version changed.
- Structured read normalization is not implemented; existing opaque comment output remains until controlled provider responses establish the actual format. This is unreleased work, not the final v0.3.0 contract.
